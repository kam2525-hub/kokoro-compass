# こもれびの羅針盤 (Komorebi Compass)

> 「生きる意味」に迷ったあなたへ。  
> 大きな意味を探すかわりに、日常の小さな光と温もりを思い出すためのWebサイト。

---

## 🌿 サイトの目的とコンセプト
お友達から「生きる意味を考えている」と打ち明けられた時、説教くさくなったり無理にポジティブを押し付けるのではなく、**「今生きていること自体の安心感」「日常のささやかな温もり」**をそっと感じられる体験を作りました。

### 主な特徴
1. **心の荷下ろし＆深呼吸ガイド**
   - 4秒吸って・4秒止めて・6秒吐く、穏やかなビジュアル呼吸サークル。
2. **心をほぐす5つのやさしい対話**
   - 文字入力がつらくても**タップだけで選べるヒントチップ**付き。
   - スキップ可能でプレッシャーを与えない設計。
   - ① 五感の心地よさ（お布団、温かい飲み物など）
   - ② 心がほどける時間（ぼーっとする、散歩など）
   - ③ 誰かとのぬくもり（ささやかな「ありがとう」）
   - ④ 小さな好奇心の芽（やってみたいこと）
   - ⑤ 人生の北極星（大切にしたい感覚）
3. **心に灯す「言葉の処方箋」**
   - フランクル（『夜と霧』）、アドラー、谷川俊太郎、老子などの温かい名言と優しい解釈。
4. **あなただけの「お守りカード（心のしおり）」生成**
   - 画像としてワンクリック保存（PNGダウンロード）。スマホ壁紙やLINE共有が可能。
   - 今日できる「0.1歩のやさしいご褒美アクション」付き。
5. **癒やしのサウンド機能**
   - Web Audio APIによるカリンバ風の心地よい音とアンビエント和音（オン/オフ可能）。外部音声ファイル不要。

## 🚀 すぐに動かす方法

### 方法1：ローカルで確認する
このフォルダで以下のコマンドを実行すると、自動的にブラウザが開きます。
```bash
python run_server.py
```
または、`index.html` を直接ダブルクリックしてブラウザで開くだけでも動作します。

---

## 🌐 お友達にシェア・公開する方法
HTML / CSS / JavaScript の完全静的構成のため、どこでも無料・数分で公開可能です。

1. **GitHub Pages**
   - リポジトリにこの3ファイル (`index.html`, `style.css`, `app.js`) をプッシュし、Settings > Pages で「main / root」を選択するだけ。
2. **Vercel / Netlify / Cloudflare Pages**
   - フォルダをドラッグ＆ドロップするだけで即座に公開URLが発行されます。
3. **LINEなどで直接共有**
   - サイトで生成した「お守り画像」を保存して、お友達に画像としてプレゼントすることもできます。
