# 人生のサブクエストガチャ (Subquest Gacha)

> 「壮大な生きる意味とか探すのやめろ！今日の生きる意味はガチャで引いて適当にこなせ！」

---

## 🎮 概要
「なんか最近生きる意味とか考えちゃうんだよね〜」とふと呟いた友達に向けて、
**「壮大な意味を探すのはやめて、今日のくだらない＆最高なミッション（サブクエスト）をガチャで引いてクリアしよう！」**
というノリで遊べるエンタメWebアプリです。

### 🌟 主な特徴
1. **ワンタップ生きる意味ガチャ**
   - カプセルを回して、今日地球に滞在する理由（サブクエスト）を排出！
   - レア度システム搭載（N / R / SR / SSR / UR）。URは全知全能級の悟り系。
   - ピコピコゲーム風SE（Web Audio API）＆SSR/UR時は紙吹雪エフェクト。
2. **クエスト受注＆達成システム**
   - 「この生きる意味を達成した！」ボタンを押すと、ハンコがドカンと押されて経験値（EXP）獲得。
   - レベルアップ機能（Lv.1 一般人 → Lv.4 二度寝の勇者 → Lv.10 現世超越神）。
3. **友達にシェア・お守り画像保存**
   - 「今日の私の生きる意味は【〇〇】でしたwww」とLINEやX (Twitter) でワンタップ共有。
   - クエストカードをPNG画像として保存も可能。
4. **達成済みクエスト図鑑**
   - ブラウザ（LocalStorage）にクリアしたクエストがコレクションとして蓄積。
